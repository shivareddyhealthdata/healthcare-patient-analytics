Healthcare Patient Analytics Dashboard

📊 Project Overview

This project analyzes a synthetic dataset of 1,000 healthcare patients to identify trends in patient demographics, departments, diagnoses, hospital utilization, costs, and length of stay.

The project demonstrates practical healthcare data analytics skills using Excel, with a focus on data cleaning, analysis, visualization, KPI development, and business insights.

🎯 Objectives

* Clean and validate healthcare patient data
* Analyze patient demographics and healthcare utilization
* Compare departments and diagnoses
* Analyze treatment costs and length of stay
* Create healthcare KPIs
* Build an interactive healthcare dashboard
* Generate actionable insights and recommendations

🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel formulas
* Data cleaning
* Data visualization
* KPI analysis
* Healthcare analytics

📈 Key KPIs

* Total Patients
* Average Patient Age
* Total Healthcare Cost
* Average Healthcare Cost
* Average Length of Stay
* Department-level patient volume

🔍 Analysis Areas

Patient Demographics

Analysis of patient age and demographic characteristics.

Department Analysis

Comparison of patient volume across healthcare departments.

Diagnosis Analysis

Identification of common diagnoses and their distribution.

Cost Analysis

Analysis of healthcare costs and cost patterns.

Length of Stay

Analysis of patient hospitalization duration.

📊 Dashboard

The Excel workbook contains an interactive healthcare analytics dashboard with KPIs, charts, and visual summaries.

💡 Key Insights

The analysis provides insights into:

* Patient distribution across departments
* Common diagnoses
* Healthcare cost patterns
* Hospital length-of-stay trends
* Areas that may require operational attention

💼 Business Recommendations

Healthcare organizations can use these insights to:

* Improve resource allocation
* Monitor department workload
* Identify cost patterns
* Optimize hospital operations
* Support data-driven decision-making
